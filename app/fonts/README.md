# Fonts

`Switzer-Variable.woff2` is **Switzer** by Indian Type Foundry, downloaded on 2026-10-09 from

of proposales.com, and it is used here so the app matches the Proposales visual language.

It is self-hosted through `next/font/local` in `app/layout.tsx`.
